# Amostra de estudo

[amostra_estudo.csv](raw/amostra_estudo.csv) deriva do CSV já versionado na análise anterior. Os nomes foram substituídos por identificadores, mantendo os valores usados nos exercícios. A origem externa e a licença ainda precisam ser documentadas. Não afirmar que a amostra representa uma instituição ou população.

Campos: aluno_id, idade, nota (pode estar ausente), aprovado_informado (status original, não recalculado pela nota).

No Colab, envie o CSV; no computador, mantenha a estrutura desta pasta.
