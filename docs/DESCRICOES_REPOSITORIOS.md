# Descrições preparadas para About

Os textos estão prontos; aplicar os campos About/tópicos depende do acesso de configuração do GitHub. A organização dos arquivos e READMEs está publicada.

## repo-clonado

Exercício inicial de Git: repositório de prática de clonagem, preservado como histórico de aprendizado.

Tópicos: git, github, learning.

## dio

Registro inicial de estudos na DIO, com acesso aos exercícios de Java e ao laboratório de open source.

Tópicos: dio, learning, git.

## js-developer-pokedex

Pokédex em HTML, CSS e JavaScript que consulta a PokéAPI, apresenta tipos e imagens e pagina os primeiros 151 Pokémon.

Tópicos: javascript, html, css, pokedex, pokeapi, dio.

## dio-trilha-java-basico

Exercícios de Java: tipos, operadores, métodos e simulação de uma Smart TV, desenvolvidos na trilha Santander/DIO.

Tópicos: java, dio, learning, object-oriented-programming.

## Animais-Extintos

Aplicação de estudo em HTML, CSS e JavaScript para pesquisar uma base local de espécies por nome, descrição e tags.

Tópicos: javascript, html, css, education, search.

## Amazon-Vendas-India

Análise exploratória em Python de valores e quantidades por estado da Índia, com comparação regional e visualizações.

Tópicos: python, pandas, data-analysis, eda, sales.

## Cronograma-BB-Digital-Week-2024

Extração de programação de eventos de PDF para Excel com Python, pdfplumber e pandas; etapa de dados de uma agenda web.

Tópicos: python, pdf, data-extraction, pandas, automation.

## Site-BB-digital-Week-2024

Agenda histórica com 173 registros de eventos em JSON, busca, filtros e ordenação, desenvolvida em HTML, CSS e JavaScript.

Tópicos: javascript, html, css, python, events, data-visualization.

## gamificacaoestatistica

Quiz de estatística em HTML, CSS e JavaScript com personagens, questões de múltipla escolha, vidas e temporizador.

Tópicos: javascript, html, css, statistics, quiz, education.

## estatistica-pos-

Versão histórica do quiz de estatística da pós-graduação. O desenvolvimento principal está em gamificacaoestatistica.

Tópicos: javascript, statistics, quiz, education.

## Dlibs---Releases

Notas de instalação de bibliotecas de visão computacional e consulta a releases de dlib, com atenção à compatibilidade do ambiente.

Tópicos: python, computer-vision, dlib, installation.

## miniguia-estudos-notebooklm

Guia de organização de fontes e reflexões sobre IA, visão computacional e inteligência espacial, inspirado em estudos sobre Fei-Fei Li.

Tópicos: artificial-intelligence, study-notes, notebooklm, computer-vision.

## dio-lab-open-source

Cópia de estudo do laboratório DIO de contribuição open source, com documentação e créditos originais preservados.

Tópicos: git, github, dio, open-source, learning.

## portfolio-dados

Catálogo central de projetos em dados, notebooks, estudos e rascunhos, com status, instruções de execução e próximos passos.

Tópicos: python, data-analysis, portfolio, machine-learning, study-notes, work-in-progress.
